## Context Guard

Do **not** inspect desktop and mobile screenshots in the same agentic tool batch. One image per agentic tool batch. Sequential A → analyze → B in one user turn is allowed. Prefer DOM/a11y/console before pixels. Tall pages: low-res overview, then a targeted crop in a later batch. Never auto-crop the top. If Context Guard denies a raw Read, retry only the derived path it names.
